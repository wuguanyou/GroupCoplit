# GroupPilot 功能驗證紀錄

日期：2026-10-01（Asia/Taipei）

本輪完成 43 項自動化檢查（包含測試容器計數）、正式建置、GroupPilot 型別檢查與桌面／手機瀏覽器操作。測試使用隔離的 D1、R2 和合成登入身分，不新增或修改正式團隊資料。

## 本輪修正

1. 重新分工不再自動改寫任務截止日，以免掩蓋逾期；AI 分工也保留截止日。
2. 日期統一以台灣時間判定；背景巡檢、建立專案日期下限與紀錄日期一致。
3. 回報選單只列出本人可回報的任務；待驗收任務不可修改進度。
4. 無可回報任務時顯示原因；驗收人固定顯示實際登入者。
5. 聊天恢復連線後清除輪詢錯誤提示，保留獨立的傳送失敗提示。
6. 頁首樣式限制在主頁首，避免影響聊天訊息；手機頂部允許換行。
7. 任務列將「預估」改標示「截止」，區分承諾日期與甘特圖預估。
8. 無任務或全完成時，巡檢狀態顯示實際原因。

## 重跑方式

先執行 `node scripts/build.mjs`。純邏輯測試：

```
node --test tests/project.test.mjs tests/project-monitor.test.mjs tests/learning-report.test.mjs tests/agent.test.mjs tests/agent-runner.test.mjs tests/auth-config.test.mjs tests/chat.test.mjs
```

建置後整合與瀏覽器測試：

```
node --test tests/full-runtime.test.mjs tests/chat-runtime.test.mjs tests/browser-audit.test.mjs
```

瀏覽器測試目前使用本機 bundled Playwright 與 Microsoft Edge，並占用 3014 埠。型別檢查限定 GroupPilot 的 app、components、lib、db 與 worker；根目錄另有獨立的 dnd-table 專案，不納入本輪範圍。

## 仍需人工或後續驗證

- 使用真實 Google／GitHub 帳號走完第三方授權回呼與正式站 Session 建立。
- 使用正式操作通行碼，在正式站完成 AI 提案與套用流程。
- 正式專案有未完成任務後，核對下一次背景巡檢時間與紀錄。
- 更多裝置、長期多人並行、大量資料及服務中斷情境尚未全面涵蓋。測試通過不能保證所有未來輸入皆無錯誤。
