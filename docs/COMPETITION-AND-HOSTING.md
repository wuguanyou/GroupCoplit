# GroupPilot 競賽方向與部署位置

更新：2026-09-21。依使用者提供的組別說明，作品以 AI 工具運用組及教育 AI 組為目標；截圖不是完整報名規則，資格與繳件要求仍以主辦方為準。

## 部署位置

- 正式網站：https://grouppilot.wuguanyou36.workers.dev
- 前端及後端 API：使用者 Cloudflare 帳號的 Workers，服務名稱 grouppilot。不是在本機持續執行，也不是 Azure VM。
- 專案、成員、驗收及登入資料：Cloudflare D1，資料庫 grouppilot。
- 原始附件：Cloudflare R2，bucket grouppilot-files。
- 生成式 AI：後端透過 Groq API 呼叫模型；憑證放 Cloudflare Secrets。模型可更換，實際設定以部署環境為準。
- 程式碼：https://github.com/wuguanyou/GroupCoplit ，獨立部署分支 codex/independent-login。
- 舊 chatgpt.site 網站為先前部署，不會隨此分支同步更新。使用正式 workers.dev 連結。
- Azure VM 在區域政策驗證階段被拒絕，尚未部署成功；依使用者改組要求停止建立。

## 兩組的展示重點

AI 工具運用組：展示生成式 AI 輸入專案要求與現況，輸出任務拆解、自然語言進度解析、分工提案及風險分析。具體執行要經過資料驗證、依賴排程、權限與版本檢查。

教育 AI 組：展示學生分組協作問題、任務交付、同儕驗收、實作證據與反思。新增的學習回饋及 Markdown 報告只整理現有紀錄，不冒充 AI 生成評語或教師成績。

## 已新增

貢獻分析頁增加團隊學習回饋及下載報告。技能實作僅依已驗收紀錄的任務分類整理；待驗收、退回與自報工時分開列出。報告保留原提交人歸屬，標記示範資料、計算方式、AI 用途與限制。下載含團隊姓名與成果說明，分享前需確認接收對象。

## 仍需完成的驗證與限制

- 真實團隊完整登入、加入、交付、驗收與 AI 流程需要端到端驗證。
- 上傳附件目前保存原始檔案，尚未解析 PDF/Office 內容供 AI 閱讀。
- Cloudflare Cron 每小時整點巡檢非示範、未完成的專案；風險改變才新增紀錄。啟用自動分工才調整負責人，保留截止日與交付歸屬。這是規則與排程引擎，不會每小時呼叫生成式 AI。站外催辦通知尚未實作。
- 學習效果需實際使用與回饋評估，不能從貢獻點數推論能力提升或自動給成績。

## 甘特圖與背景巡檢

任務頁加入依剩餘工時、每日可用時間及前置依賴計算的預估甘特圖，支援負責人篩選。長條不代表實際工作紀錄。頁尾顯示最近背景巡檢時間。

排程設定：wrangler.jsonc 的 0 * * * *，由 worker.ts scheduled handler 執行。資料更新使用 revision 比對，遇到使用者同時更新便跳過，下一次再檢查。示範與已完成專案跳過。

驗證：型別檢查、正式建置、9 項排程與巡檢測試通過；使用 Miniflare 直接觸發已建置 Worker 的 scheduled handler，獨立本機 D1 成功更新一次，同小時再次觸發不重複寫入。Wrangler HTTP 定時測試入口遇到 ScheduledController 序列化錯誤，故採直接事件測試。正式排程的實際執行仍需觀察部署後紀錄。
