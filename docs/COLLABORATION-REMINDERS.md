# 協作與期限提醒（2026-10-02）

正式網站：https://grouppilot.wuguanyou36.workers.dev/

## 新增功能

- 通知中心：個人通知、未讀數、單筆與全部已讀。
- 專案建立者可開啟到期提醒；預設關閉。
- 每小時巡檢，在台灣時間 09:00–20:59 產生站內提醒。到期前一天、當日、逾期提醒，同任務、負責人、截止日每日最多一次。待驗收與完成任務停止提醒。
- 團隊聊天室顯示最近 10 筆期限提醒；負責人可直接開啟進度回報或提交成果。快速回報選單連至結構化表單，不會自動解析一般聊天。
- 任務留言與提及組員；提及產生站內通知。重試送出以 requestId 去重。
- 專案建立者可設定個別任務截止日，變更保留紀錄。

## 儲存與限制

資料沿用 D1 projects JSON，並以 revision 避免覆蓋同時更新，不需新增資料表。每專案保留最近 1,000 筆任務留言與 500 筆通知；聊天室 SQL 訊息沿用既有機制。

尚未串接 Email、LINE 或瀏覽器推播。附件保存原檔，尚未自動解析內容。背景巡檢使用可驗證的排程規則，不會每小時呼叫生成式模型。模型工作台仍需服務可用、設定與操作通行碼。
