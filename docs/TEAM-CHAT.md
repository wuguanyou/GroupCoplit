# 團隊聊天室

- 入口：專案左側「團隊聊天室」。訊息保存於 Cloudflare D1 的 chat_messages，依專案隔離。
- 只有已登入的專案成員可以讀取與傳送；作者來自伺服器登入狀態。
- 每則訊息最多 2000 字，支援換行。內容以純文字呈現，不執行 HTML。
- 聊天頁面開啟時，每 5 秒拉取新訊息；背景分頁暫停輪詢。不是 WebSocket 即時推播。
- 初次顯示最近 50 則，可載入更早訊息。使用序號增量更新避免漏掉大量新訊息。
- 傳送失敗保留草稿，未更改內容的重試使用同一識別碼避免重複。
- 向上閱讀時停止自動跳到底部，可按「查看最新訊息」返回。
- 此版本沒有私訊、附件、已讀狀態、站外通知或 AI 自動讀取聊天內容。

驗證：`node --test tests/chat.test.mjs`；建置後執行 `node --test tests/chat-runtime.test.mjs`，以隔離的本機 D1 和兩位合成登入成員驗證收發、權限和重複請求。部署前先套用 0004 資料庫遷移。
